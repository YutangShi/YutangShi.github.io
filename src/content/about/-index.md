你好，我是 Allen Shi。我喜歡把複雜的事情整理成能穩定運作的系統：從早期接觸 POS、進銷存、購物網站與企業 App，到後來投入雲端平台、基礎設施自動化與 SRE，這份工作始終讓我享受在問題裡找出脈絡，並把事情一步步做得更可靠。

我習慣先理解服務之間怎麼互相影響，再處理眼前的問題。無論是部署流程、監控告警或日常維運，我相信好的做法不只解決一次狀況，也能讓團隊往後少花一點力氣。持續學習新技術、和不同角色合作，以及把經驗分享出去，都是我很在意的事。

## 主要領域

- **雲端平台與 SRE**：規劃並維護 AWS、Azure 與混合環境，涵蓋 Kubernetes、網路路由、負載平衡、身分驗證、憑證與資安維運。
- **基礎設施即程式碼與交付流程**：使用 Terraform、Puppet、Docker、Helm、Argo CD、GitLab CI/CD 與 Jenkins 建立可追蹤、可重現的部署流程。
- **可觀測性與資料庫可靠性**：以 Prometheus、Alertmanager、Grafana、Thanos、PMM 與 exporter 建置監控、告警與診斷能力；熟悉 MySQL、PostgreSQL、Aurora 與讀寫分流維運。
- **應用與商務系統開發**：具備 PHP、Laravel、CodeIgniter、Java、Vue.js、NativeScript、Python 等技術實作經驗，能處理 POS、訂單、庫存、會員、交易與企業營運系統需求。
- **AI 應用概念驗證**：持續探索語音轉文字、語音合成、在地語言模型、圖像與音樂生成等 AI PoC，並評估其在流程自動化與互動服務中的落地方式。

## 做過的案例

### 雲端平台與維運自動化

- 以 Terraform 建置 AWS EKS 管理服務，搭配 Helm 與 Argo CD 管理 Kubernetes 設定與部署。
- 規劃跨 VPC 與地端環境的網路路由整合，降低 Peering 與 Site-to-Site VPN 的維護複雜度。
- 導入 Consul、Nomad 與 Vault 的設定、服務部署與機密管理模式，支援微服務運行。
- 建立 GitLab Server、Runner 與 Registry Mirror 的維運與優化流程，提升開發與部署效率。
- 導入資料庫監控、雲端服務檢視與容器化策略，曾協助降低基礎設施成本約 35%。

### 可觀測性與服務可靠性

- 整合 Prometheus、Alertmanager、Grafana、Thanos、PMM 與多種 exporter，建立從指標蒐集、視覺化到 on-call 告警的監控鏈路。
- 處理 Linux 系統安全更新、憑證更換、網路設備調整與服務障礙排除，並以 Shell 與 Python 自動化日常檢查與資料同步。
- 協助導入 OpenID Connect 與 SAML 等身分驗證整合，提升服務存取安全性。

### 產品與系統開發

- 從需求訪談、資料庫設計到上線導入，參與多店家訂單結帳、餐飲與零售 POS、進銷存、會員、購物與營運後台系統的完整生命週期。
- 開發跨平台 App 與 RESTful API，支援庫存調度、門市管理、預約、維修、專案報價、發票驗證與即時訂單通知等場景。
- 以 Vue.js、Docker Compose 與 Laravel 等技術推進前後端分離、環境標準化、版本升級與自動部署。
